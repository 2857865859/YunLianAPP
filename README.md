# YunLianAPP · 云链助手

Android 网盘下载工具，支持 **夸克、UC、迅雷网盘**，采用多线程分片下载。

## 功能

- 分享链接识别、解析，浏览分享文件和文件夹
- 夸克、UC、迅雷网盘登录与账号管理
- 多线程 Range 分片下载、断点续传、暂停和继续
- 下载任务管理、实时进度与速度显示
- 下载速度最高可达约 **50 MB/s**；实际速度取决于网络、设备、文件与网盘服务，截图显示 **48.2 MB/s**
